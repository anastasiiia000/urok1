# Публикация сайта «Дело № 01» через GitHub Pages

## Структура файлов

Загружайте содержимое этой папки в корень репозитория, сохраняя структуру:

- `index.html`
- `style.css`
- `screen_fit.css`
- `app.js`
- `.nojekyll`
- `assets/` — все изображения сайта

**Важно:** папку `assets` нужно загрузить целиком. Не переименовывайте её и не переносите изображения в корень репозитория.

## Публикация

1. Распакуйте архив.
2. Откройте репозиторий GitHub.
3. Загрузите файлы из распакованной папки в корень репозитория. Если сайт должен публиковаться из папки `docs`, поместите туда всю структуру целиком.
4. Откройте `Settings` → `Pages`.
5. В `Build and deployment` выберите `Deploy from a branch`.
6. Выберите нужную ветку (обычно `main`) и папку публикации (`/(root)` либо `/docs`, куда загрузили сайт).
7. Нажмите `Save`.

## Проверка, если картинки не появились

- Убедитесь, что в корне выбранной папки публикации есть `index.html`.
- Убедитесь, что рядом с ним есть папка `assets`.
- Внутри `assets` должны находиться `figure_01.jpg`, `figure_02.jpg`, `figure_03.jpg`, `figure_04.jpg`, `figures_collection.jpg`, `collectible_box.jpg`, `packaging_layout.jpg` и пиксельные изображения.
- Проверьте написание имён: GitHub Pages различает `Figure_01.jpg` и `figure_01.jpg`.
- После загрузки обновите сайт с принудительным обновлением страницы: `Ctrl + F5`.

Изображения подключаются относительными путями вида `assets/figure_01.jpg`; так сайт корректно работает как в корне GitHub Pages, так и внутри `/docs`, если вся структура перенесена вместе.
